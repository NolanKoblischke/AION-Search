# GZ10 Pipeline (AION-Search + LLM Descriptions)

This folder contains the Galaxy10 classification benchmark pipeline used in the paper:
- Step 1: generate AION-Search embeddings from the Hugging Face dataset
- Step 2: generate VLM descriptions for Galaxy10 images
- Step 3: run zero-shot and LLM-judge classification
- Step 4: train an MLP probe on frozen AION-Search embeddings

## Requirements
- `OPENAI_API_KEY` for label embeddings in Step 1, OpenAI descriptions/text embeddings in Step 2
- `OPENROUTER_API_KEY` for OpenRouter models in Step 2
- `GEMINI_API_KEY` for LLM-judge classification in Step 3
- AION-Search model weights from [astronolan/aion-search](https://huggingface.co/astronolan/aion-search). The scripts download `config.json` and `model.safetensors` automatically unless a local `--model-path` checkpoint exists.
- Hugging Face dataset: `astronolan/galaxy10-aion`

## Step 1: Generate AION-Search embeddings
Loads the HF dataset, encodes cutouts with AION, projects through the AION-Search CLIP head, and builds class-label text embeddings.

```bash
uv run python -m src.experiments.gz10.step1_prepare
```

Optional flags:
- `--split <str>`: HF dataset split (default: `test`)
- `--batch-size <int>`: AION encoding batch size
- `--model-path <path>`: optional local PyTorch checkpoint; defaults to `data/gz10/aionsearchmodel.pt`, and falls back to `astronolan/aion-search` if absent

Outputs:
- `data/gz10/gz10_image_embeddings.parquet`
- `data/gz10/gz10_label_embeddings.parquet`

## Step 2: Generate LLM descriptions
Submit a batch job with OpenAI, or run direct requests through OpenRouter:

```bash
uv run python -m src.experiments.gz10.step2_describe --submit --model gpt-4.1-mini
uv run python -m src.experiments.gz10.step2_describe --submit --model qwen/qwen3-vl-235b-a22b-thinking
```

Check and download results:

```bash
uv run python -m src.experiments.gz10.step2_describe --check <BATCH_INFO_JSON>
```

Embed descriptions:

```bash
uv run python -m src.experiments.gz10.step2_describe --embed <DESCRIPTIONS_RAW_PARQUET>
```

Useful flags:
- `--limit <n>` to reduce samples for testing
- `--no-images` to send prompt-only requests without images
- `--resume <CHECKPOINT_FILE>` to resume interrupted OpenAI uploads

## Step 3: Zero-shot and LLM classification
Run AION-Search zero-shot classification:

```bash
uv run python -m src.experiments.gz10.step3_classify --aion
```

Outputs:
- `data/gz10/gz10_aion_classifications.parquet`
- Confusion matrix image in `data/gz10/`

Run description-based classification:

```bash
uv run python -m src.experiments.gz10.step3_classify --llm-similarity --descriptions <DESCRIPTIONS_WITH_EMBEDDINGS>
uv run python -m src.experiments.gz10.step3_classify --llm-judge --descriptions <DESCRIPTIONS_WITH_EMBEDDINGS>
uv run python -m src.experiments.gz10.step3_classify --all --descriptions <DESCRIPTIONS_WITH_EMBEDDINGS>
```

## Step 4: MLP probe on AION-Search embeddings
Train a two-layer MLP classifier on frozen AION-Search embeddings using the AION-1 paper protocol. This is the pipeline for the paper's `AION-Search + MLP probe` result.

```bash
uv run python -m src.experiments.gz10.step4_finetune
```

Useful flags:
- `--epochs <int>`: training epochs
- `--lr <float>`: learning rate
- `--batch-size <int>`: classifier training batch size
- `--device <str>`: override device
- `--model-path <path>`: optional local PyTorch checkpoint; defaults to `data/gz10/aionsearchmodel.pt`, and falls back to `astronolan/aion-search` if absent

Outputs are written under `data/gz10_ft/`, including cached embeddings, predictions, and training metrics.

## Paper Figure
The static confusion-matrix figure is generated by:

```bash
uv run python -m src.experiments.gz10.analysis.paper_confusion_matrix \
    --left data/gz10/gz10_aion_classifications.parquet \
    --right <LLM_JUDGE_CLASSIFICATIONS_PARQUET>
```
